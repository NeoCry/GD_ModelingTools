# ModelingTool — аддон для 3D-редактора Godot

1. Скопируйте папку `addons/modeling_tool` в свой проект. Поставляемые DLL предназначены для **Windows x64, Godot 4.4+**.
2. Откройте проект **в редакторе Godot**. Если он уже открыт, перезапустите редактор для загрузки GDExtension.
3. В **Project → Project Settings → Plugins** включите **ModelingTool**.
4. Откройте свою 3D-сцену с корневым **Node3D**. Справа появится вкладка **Modeling**.
5. Нажмите **Create → Box**, **Cylinder**, **Pyramid** или **Sphere**. Примитив появляется как EditableMesh и выделяется в дереве сцены. Создание поддерживает Undo/Redo.
6. На верхней панели 3D viewport включите **Modeling: Edit polygons**. В панели Modeling выберите Vertex / Edge / Face и редактируйте геометрию прямо в viewport.
   После выделения элементов выберите рядом иконки **Move (W) / Rotate (R) / Scale (S)**. Rotate показывает три кольца с точками для перетаскивания; Scale — осевые ручки и белую ручку равномерного масштаба. Вращение и масштабирование выполняются вокруг центра выделения в локальных осях. Ctrl включает шаг: Move 0.1, Rotate 15°, Scale 0.1. Это кнопки Modeling; обычные инструменты Godot предназначены для целых объектов.
7. Для выбора, перемещения, вращения и масштабирования целых объектов выключите **Modeling: Edit polygons**. **Tab** переключает эти режимы, когда выбран EditableMesh.
8. Сохраняйте сцену обычным **Ctrl+S**. PolyMesh хранится в ней как ресурс; отдельный экспорт для блокаута не требуется. Undo/Redo интегрирован с редактором.

**F5 не требуется**: он запускает игру, а не инструменты аддона.

Обводка меша — зелёная, толщиной 2 экранных пикселя. Выделенные рёбра и маркеры вершин — красные; выбранные грани имеют красную границу и красную заливку с непрозрачностью 25%. Эти слои не меняют материал меша и не сохраняются в экспортируемую геометрию. X-ray включает отображение выделения сквозь поверхности.

В режимах Vertex и Edge достаточно навести курсор **рядом** с элементом: ближайший видимый кандидат подсвечивается жёлтым, в панели показывается его ID. Щелчок выбирает подсвеченный элемент, Shift переключает его выделение. Уже выбранный кандидат остаётся красным, но его маркер/обводка увеличивается. **Pick radius (px)** задаёт область попадания (20 px по умолчанию, диапазон 4–48 px). Маркеры вершин имеют постоянный экранный размер 7 px, при наведении — 11 px; контур ребра при наведении — 4 px. Без X-ray скрытые поверхностью этого меша элементы не выбираются; учитывается видимость самого кандидата, а не поверхности под соседней точкой курсора.

Материал блоков — обычный серый `materials/blockout_gray.tres`, без текстуры и трипланарной проекции. Старый путь `world_checker.tres` сохранён как серый материал для совместимости с уже сохранёнными сценами. Пользовательские материалы не заменяются.

Можно преобразовать существующий MeshInstance3D кнопкой **Create → Import Selected**. Оригинал сохраняется скрытым; отмена возвращает его. Поддерживаются статические меши, без skinning/UV2/blend shapes. Подробное API и ограничения геометрических операций описаны в README исходного проекта.

## Разрезы и лупы

**Ctrl+R / Loop cut** — наведите на ребро для предпросмотра, колесом задайте число разрезов. Щелчок включает сдвиг мышью, следующий щелчок или Enter подтверждает; Ctrl задаёт шаг сдвига. ПКМ при сдвиге оставляет разрезы по центру, Esc отменяет операцию. Разрез проходит по четырёхугольникам и останавливается у границы или других типов граней.

**K / Knife** — начните на ребре/вершине, щелчками задайте траекторию, закончите на ребре/вершине. Допускаются промежуточные точки внутри граней; пересечения видимых рёбер добавляются автоматически. Enter/Space применяет все завершённые разрезы, Esc отменяет всё. ПКМ начинает отдельный путь и отбрасывает незавершённый хвост. Сквозной рез и замкнутые контуры целиком внутри грани не поддерживаются; пересекающиеся новые траектории подтверждайте по отдельности.

**Двойной щелчок рядом с ребром** выбирает луп: рёбра в Edge, вершины в Vertex, поперечную полосу quad в Face. Shift добавляет луп. Обход останавливается при неоднозначном продолжении.

Предпросмотр жёлтый; после подтверждения новые элементы выделены красным. Один разрез или группа разрезов отменяется одним Undo. После обновления DLL перезапустите редактор.

## Bevel

Выделите рёбра в Edge и нажмите **B / Bevel**. Перетаскивайте жёлтую ручку с зажатой ЛКМ для изменения ширины. Отпустите кнопку, чтобы зафиксировать ширину; можно снова захватить ручку. Движение курсора без перетаскивания ничего не меняет. Колесо над ручкой меняет сегменты (1–32), вне ручки — зум. Ctrl при перетаскивании включает шаг 0.1. Enter/Space подтверждает, Esc отменяет. ПКМ отменяет во время перетаскивания; вне перетаскивания доступна навигация камеры. Amount и Segments задают начальные значения. Ошибка чрезмерной ширины не меняет геометрию: уменьшите ширину или отмените. Поддерживаются отдельные и смежные внутренние рёбра с выпуклыми углами граней; сложные стыки с неодинаковыми отступами пока отклоняются.

В Edit polygons стандартное гизмо объекта скрыто, пользовательские ручки Move/Rotate/Scale работают с выделением. В Object mode стандартное гизмо возвращается. Сохранение сцены отменяет неподтверждённый Bevel, чтобы временная геометрия не попала в файл.

## Plane и Boolean

**Plane** — редактируемый квадрат 2×2 в XZ с нормалью вверх. Создание поддерживает Undo/Redo.

Выберите два меша в дереве сцены и нажмите **Union / Difference / Intersection**. Difference вычитает второй выбранный меш из первого. Создаётся отдельный EditableMesh, исходники скрываются. Undo возвращает оба исходника, Redo — результат.

Boolean работает через CSG Godot для замкнутых статических сеток и создаёт треугольную геометрию. Открытый Plane сначала нужно превратить в замкнутый объём. Входные узлы не должны быть предками друг друга. Пустой результат или ошибка сохраняют исходники без изменений.

Активные инструменты в доке Modeling подсвечиваются синим, как на верхней панели; разовые операции подсвечиваются при нажатии.

## Inset: управление

Выделите полигоны в Face и нажмите **I / Inset**. Жёлтая ручка управляет отступом только при перетаскивании с зажатой ЛКМ. Отпустите кнопку, чтобы зафиксировать значение; можно повторно захватить ручку. Ctrl включает шаг 0.1. **Enter/Space** применяет, **Esc** отменяет. Amount задаёт начальный отступ; колесо вне перетаскивания сохраняет зум. При выделении нескольких граней Inset выполняется для каждой отдельно. Поддерживаются плоские выпуклые грани.

Предпросмотр поддерживает Undo/Redo после подтверждения. Смена объекта, инструмента, режима выделения и сохранение сцены отменяют неподтверждённый Inset.

## UV Unwrap

**Open UV Editor** открывает отдельное окно ручного редактирования UV выбранного меша. **Texture → Load Atlas or Material...** загружает изображение или Texture2D/StandardMaterial3D/ORMMaterial3D; отображается albedo-текстура. **Texture → Apply Background Material to Mesh** отдельно назначает материал всему мешу и отключает triplanar с поддержкой Undo. ShaderMaterial не поддерживается.

ЛКМ выбирает островок, Shift+ЛКМ добавляет/снимает выделение, A выбирает всё. Move / Rotate / Scale меняют выделенные островки перетаскиванием вокруг общего центра; U / V / Angle / Scale и Apply — точный числовой ввод. Ctrl включает шаг. Колесо масштабирует вид, средняя кнопка перемещает его, F вписывает UV. Esc/ПКМ отменяет предпросмотр; отпускание ЛКМ применяет изменение. Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y — история сцены. Изменение геометрии меша для этого не требуется.

Окно закрепляется за открытым в нём мешем. Для переключения выберите другой меш и повторно нажмите Open UV Editor. Сохранение — Ctrl+S в главном редакторе или Save .tres. Поддерживается редактирование целых островков; отдельных UV-вершин пока нет.

**Cube / Cylinder / Sphere** и **Top (XZ)** находятся в разделе **Projection** окна UV и меняют UV выбранных в нём островков; при пустом выделении — всего меша. Проекции используют локальные координаты, Cylinder — ось Y. Углы полигонов хранят независимые UV для швов. Cylinder и Sphere могут переходить через U=1; для текстуры используйте Repeat. Cube раскладывает направления по ячейкам, но не устраняет все наложения на сложных поверхностях.

**Projection → OptCuts** запускает реальный OptCuts для всего меша в фоне. Windows x64 решатель включён в аддон; отдельная установка не нужна. Раздельные компоненты обрабатываются автоматически. Результат триангулирован, позиции и материалы сохраняются, UV укладываются в 0–1. Нумерация элементов и edge-атрибуты могут измениться. Undo возвращает исходную сетку. **Cancel** рядом с OptCuts отменяет расчёт; 3 минуты на компоненту — предельное время. Ошибки и изменения меша во время вычисления не приводят к перезаписи текущей работы. Логи: `.godot/modeling_optcuts/`.

Для просмотра UV назначьте текстуру и отключите triplanar у материала. Сам материал инструменты не меняют.

Решатель взят из [TopoPPI v2.1](https://github.com/GeraltZeroZhong/TopoPPI/releases/tag/v2.1), алгоритм — [OptCuts](https://github.com/liminchen/OptCuts). Лицензии всех включённых зависимостей находятся в `bin/optcuts/`. В частности, Triangle 1.6 требует разрешения автора для распространения в коммерческой системе.

## Верхняя панель: управление

**1 / 2 / 3 верхнего ряда** переключают Vertex / Edge / Polygons для выбранного EditableMesh при фокусе в 3D-виде или верхней панели Modeling; **A** выделяет всё. Работают также в меню Selection. Поля ввода, NumPad и сочетания с модификаторами сохраняют стандартное поведение.

В однострочной панели над 3D-видом находится меню **Selection**: Vertex / Edge / Polygons, All / None / X-ray и радиус выбора. Нижние подсказки скрыты. Выбор режима или All автоматически включает Edit Polygons для выбранного меша; обычный MeshInstance3D при выборе через меню преобразуется в редактируемую копию с поддержкой Undo. Клавиши 1 / 2 / 3 / A также включают редактирование выбранного EditableMesh. Активные кнопки подсвечены синим, закрытое меню показывает текущий режим.

Выпадающее меню **Snap** рядом с Move / Rotate / Scale включает привязку **Grid / Vertices / Edges** для гизмо Move и показывает шаг сетки.

**Центральная ручка Move** свободно перемещает центр выделения к вершине или точке на ребре соседнего меша. Голубой маркер показывает цель; допуск задаётся Pick radius. Осевые ручки сохраняют движение по своей оси. Привязка не сваривает вершины и поддерживает Undo/Redo.

При наведении и перетаскивании подсвечивается вершина или всё ребро. Близкая вершина имеет приоритет над ребром. Осевые ручки выравнивают центр выделения по проекции цели на ось, даже когда цель находится в стороне от линии движения; пунктир показывает это соответствие.

**Grid** использует мировой шаг из **Godot → Transform → Configure Snap → Translate Snap**. Ctrl временно включает сетку, Shift уменьшает шаг в 10 раз. Привязка к геометрии приоритетнее сетки. Для повёрнутой оси сетка применяется по главной мировой координате оси.

Поддерживаются EditableMesh и статические MeshInstance3D; обычные меши предоставляют рёбра треугольников, включая диагонали. X-ray разрешает привязку сквозь соседние поверхности. Эти переключатели относятся к перетаскиванию Move; операторы Bevel/Inset и числовые трансформации сохраняют собственное поведение.

### Texel Density и пользовательские швы

В окне UV **Texel Density** показывает `sqrt(UV area × atlas width × atlas height / world surface area)` в пикселях на единицу Godot. Учитывается мировой масштаб объекта, в том числе неравномерный. При выделении считается суммарная площадь выбранных островков, иначе — всего меша; пересекающиеся UV учитываются отдельно. Плотность обновляется и во время предпросмотра трансформации. Это средняя по площади плотность, а не оценка анизотропных искажений каждого треугольника. Размер берётся из загруженной текстуры; без текстуры задаётся полями Atlas W/H (по умолчанию 1024×1024).

Выделите рёбра нужного меша в 3D-редакторе и нажмите **Seams → Mark** в окне UV. Невыделенные швы отображаются фиолетовым. **Clear** снимает отметки. **Unwrap Seams** разворачивает весь меш по отмеченным швам. Отметки сохраняются в PolyMesh; пометка и развёртка поддерживают Undo/Redo, не меняя геометрию. OptCuts использует собственные разрезы и может сбросить edge-атрибуты при импорте результата.

Развёртка по швам использует **LSCM (Least Squares Conformal Mapping)** со свободной границей и двумя автоматически выбранными опорными вершинами. Это семейство алгоритмов, используемое режимом [Conformal в Blender](https://docs.blender.org/manual/en/5.0/modeling/meshes/editing/uv.html). Собственная реализация решает взвешенную по площади систему методом сопряжённых градиентов; ABF/Minimum Stretch и ручные UV pins не реализованы. Поддерживаются открытые островки, включая плоские поверхности с отверстиями. Замкнутые поверхности требуют швов. Вырожденные, перевёрнутые треугольники и несходимость отклоняются без изменения UV; глобальные самоперекрытия внутри сложного островка не устраняются автоматически. Островки нормализуются по площади для одинаковой относительной Texel Density, затем упаковываются прямоугольниками с отступом в 0–1. Это не полная копия возможностей Blender; на сложных поверхностях могут потребоваться дополнительные швы.

Окно UV помечено **Always on top** и остаётся поверх редактора. Для выбранных островков отображается **2D-гизмо**: Move — стрелки U/V и центральная ручка свободного перемещения; Rotate — кольцо; Scale — осевые квадраты и центральная ручка равномерного масштаба. Подсветка жёлтым показывает ручку под курсором. Перетаскивание ручки выполняет одну операцию Undo/Redo, Esc/ПКМ отменяет её; Ctrl включает шаг. Прямое перетаскивание островков также сохранено.

### Weld, Merge, пивот и кисть (0.1.21)

- **Weld** включает перетаскивание вершины на другую вершину текущей сетки. Цель подсвечивается жёлтым; отпустите ЛКМ над ней, чтобы сварить точки точно в положении цели. Отпускание вне вершины ничего не меняет. Повторное нажатие кнопки или Esc выключает инструмент. Неманифолдные рёбра разрешены; повреждённые данные отклоняются без изменения меша. **Weld All** остаётся отдельной сваркой по расстоянию; низкоуровневый оператор API `merge` сохранён для совместимости.
- **Merge Objects** объединяет выбранные в дереве сцены MeshInstance3D/EditableMesh в новый EditableMesh. Между объектами вершины не свариваются, даже если совпадают. Сохраняются мировые позиции, полигоны EditableMesh, UV, материалы и атрибуты рёбер. Оригиналы остаются скрытыми; Undo восстанавливает их. Для обычных MeshInstance3D используется импорт статических треугольных поверхностей.
- **Mass Center** переносит начало объекта в объёмный центр для замкнутой сетки (равномерная плотность), либо в центр поверхности по площади для открытой. **World Origin** устанавливает его в (0,0,0) сцены. **Place Pivot** включает размещение кликом с привязкой к выбранному типу: Vertex, Edge, Polygon, включая соседние видимые меши. Режим сам включает соответствующую геометрическую привязку; голубой маркер показывает точку назначения. Геометрия и обычные дочерние узлы сохраняют мировое положение. Для пивота создаётся отдельный PolyMesh, чтобы не менять другие экземпляры общего ресурса; Undo восстанавливает исходный ресурс. Это пивот объекта: вращение выделенных полигонов по-прежнему использует центр выделения.
- **Polygon Brush** включает круговую кисть: ЛКМ добавляет полигоны, Shift+ЛКМ убирает. Радиус задаётся в пикселях рядом с кнопкой или колесом мыши. X-ray разрешает выделять скрытые полигоны, без него проверяется видимость. Esc или повторное нажатие выключает кисть. Выделение, как и обычное выделение в аддоне, не создаёт шаг геометрического Undo.

Weld, Merge и изменение пивота поддерживают историю сцены Undo/Redo. Переключение объекта или инструмента отменяет незавершённое перетаскивание Weld.

### Примитивы и деформации (0.1.22)

Иконки примитивов теперь открывают предпросмотр в 3D-виде. **Sides** задаёт число сторон цилиндра/сферы, **Rings** — широтные сегменты сферы, **Subdivisions** — число шагов разбиения поверхности любого примитива (0–3). Количество итоговых полигонов показано в сообщении панели. **Enter / Apply** создаёт объект одним шагом Undo; **Esc / Cancel** удаляет предпросмотр. Предпросмотр не принадлежит сохраняемой сцене.

**Bend / Taper / Twist** открывают параметры вверху панели: локальная ось X/Y/Z, угол в градусах (Bend/Twist) либо Amount (Taper), границы Low/High в диапазоне 0–1 относительно размеров меша. Bend изгибает вдоль выбранной оси, Twist наращивает поворот от нижней границы к верхней, Taper меняет поперечный масштаб от 1 до `1 + Amount`. За границами сохраняется конечное воздействие; Bend продолжает край касательно. Для плавной формы сначала добавьте геометрические сегменты. Операции работают со всем текущим мешем, сохраняют UV/материалы/топологию и пересчитывают нормали. Enter применяет, Esc восстанавливает исходный ресурс, результат поддерживает Undo/Redo. Это применяемые деформации с предпросмотром, а не постоянный стек Maya с анимируемыми узлами. Ориентир параметров — [Maya Nonlinear Bend](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Modeling/files/GUID-4011B59F-D1D7-4368-8E4C-BBBB14AF799F.htm).

**Weld / Weld all** разрешают рёбра с более чем двумя соседними гранями. Такая геометрия сохраняется, загружается, поддерживает Undo/Redo и дальнейшее редактирование; отдельные инструменты, которым необходим manifold-меш, могут иметь собственные ограничения. Проверки несуществующих вершин, вырожденных граней и прочих повреждённых данных сохранены. В API `merge`/`weld` это опция `allow_non_manifold: true`; `validate()` по-прежнему сообщает диагностическое состояние.

**Place Pivot** отображает текущий пивот белой окружностью и цветными осями даже без выделения элементов. Голубой маркер отдельно показывает цель привязки.
